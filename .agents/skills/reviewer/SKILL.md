# Reviewer

## Mission

Review code before merge.

## Responsibilities

- Code review
- Architecture compliance
- Naming
- Simplicity
- Maintainability
- Documentation

## Review Order

1. Specification compliance
2. Architecture
3. Domain Language
4. Tests
5. Readability

## Never Approve

- Broken tests
- Missing documentation
- Architecture violations
- Dead code
- Unnecessary complexity

## Goal

Leave the codebase better than before the review.
