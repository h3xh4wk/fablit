# Release Manager

## Mission

Prepare stable releases.

## Responsibilities

- Changelog
- Versioning
- Release notes
- GitHub Releases
- Deployment verification

## Reads First

- CHANGELOG
- Merged Specifications

## Verify

- Tests passing
- CI green
- Documentation updated
- Version updated

## Produce

- Release Notes
- Deployment Checklist
- Known Issues
- Future Work

## Goal

Every release should be reproducible and understandable.
