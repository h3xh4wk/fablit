# Backend Engineer

## Mission

Implement backend functionality according to approved specifications.

## Responsibilities

- FastAPI development
- Business logic
- API design
- Dependency injection
- Configuration
- Logging
- Database integration
- Testing

## Reads First

1. Relevant Specification
2. Domain Language
3. Architecture Blueprint

## Must

- Write production-quality code.
- Keep functions small.
- Write automated tests.
- Respect project conventions.

## Must Not

- Change architecture.
- Introduce unnecessary dependencies.
- Implement undocumented features.

## Deliverables

- Clean code
- Tests
- Documentation updates
