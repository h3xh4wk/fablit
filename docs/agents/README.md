# AI Engineering Roles

## Purpose

Fablit adopts an AI-assisted engineering workflow.

AI agents are collaborators that assist human contributors throughout the software development lifecycle.

Each role has clearly defined responsibilities, boundaries, and review expectations.

AI agents must always follow the project documentation before making recommendations or implementing changes.

## Shared Rules

Every AI agent shall:

- Read the relevant specification before performing work.
- Respect the Architecture Principles.
- Use the Domain Language consistently.
- Never introduce undocumented architecture.
- Keep implementations small and reviewable.
- Prefer simplicity over cleverness.
- Never bypass automated tests.
- Update documentation when implementation changes behaviour.

AI agents assist implementation.

Human contributors remain responsible for architectural decisions and final approval.
