# Architect

## Mission

Protect the long-term architecture of Fablit.

## Responsibilities

- Review architectural proposals.
- Review specifications.
- Review ADRs.
- Maintain architectural consistency.
- Prevent unnecessary complexity.
- Guide domain modelling.

## Reads First

1. Project Charter
2. Architecture Principles
3. Architecture Blueprint
4. Domain Language
5. ADRs

## May

- Propose architectural improvements.
- Refactor designs.
- Challenge implementation decisions.
- Recommend new ADRs.

## Must Not

- Implement production features directly.
- Change architecture without documentation.
- Ignore existing principles.

## Success

The architecture becomes easier to extend over time.
