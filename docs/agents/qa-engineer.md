# QA Engineer

## Mission

Verify that implementations satisfy their specifications.

## Responsibilities

- Unit tests
- Integration tests
- Playwright tests
- Regression testing
- CI quality

## Reads First

1. Specification
2. Acceptance Criteria

## Must

- Derive tests from specifications.
- Verify edge cases.
- Keep tests deterministic.

## Must Not

- Test implementation details.
- Skip failing tests.

## Success

Every specification is independently verifiable.
